# 循图

原神地图叠加原型。用自己截取的局部地图建立区域，在底图上分色绘制路线、放置图片标记，并在游戏小地图上显示。

适用于 Windows 10 2004 及以上／Windows 11（64 位），游戏需使用窗口化或无边框窗口、小地图固定朝北。目前仍是原型，尚未完成真实游戏连续跑图验收。

## 使用

已有打包文件时，打开 `RouteOverlay.exe`；源码目录中可双击 `启动原型.cmd`。分发时请保留完整程序文件夹。

1. 选择游戏窗口，点击主界面的“小地图位置设置…”框选小地图。
2. 打开游戏大地图，调整到地形清楚的局部区域，点击“从游戏大地图建立区域”。
3. 框选地图并绘制路线，按 Enter 确认；关闭游戏大地图，点击“开始叠加”。
4. 保存为 `.routepack`，下次可打开继续绘制、移动或修改标记。也可先点击“加载离线演示（合成地图）”体验。

“画笔颜色”用于下一笔。点击“导入 PNG 标记”后，在底图上点击放置，可反复放置同一图标，按 Esc 结束。在“标记”模式点击已有图标即可选中，拖动可移动，也可调整大小或删除。标记的中心跟随地图位置，图标在缩放时保持固定的显示尺寸。Ctrl+Z 可撤销当前编辑会话里的笔画和标记操作。

新版 `.routepack` 保存定位底图、透明墨迹、独立 PNG 素材和标记位置。使用新版前请建立新区域。

快捷键：**Ctrl+Alt+F8** 在游戏地图上画线，**Ctrl+Alt+F9** 开始／停止叠加，**Ctrl+Alt+F10** 停止并返回控制台。

路线显示后，点击主界面“截图模式”或按 **Ctrl+Alt+F11**。路线会冻结，此时可用 QQ 截图或 PrtSc 框选屏幕。再次点击开关或按快捷键即可恢复定位。切到其他窗口时路线会暂时隐藏，回到游戏后截图模式仍然开启。建议在移动角色前关闭截图模式。

侧栏左下角的齿轮小按钮打开独立设置面板，左侧预留分类导航。“通用”中的“实时同步小地图”控制主界面的低频画面预览，默认开启，更改后自动保存；关闭同步不影响路线叠加。小地图位置框选保留为主界面的独立功能入口。

“通用 → 窗口行为”中的“开始叠加后自动最小化”默认开启，启动叠加时最小化程序并切回游戏。关闭后，点击“开始叠加”会保留当前窗口，手动切回游戏即可显示叠加层。停止并返回后保留原来的最大化状态或普通窗口大小。

游戏必须处于前台且画面可见；窗口尺寸或游戏 UI 布局变化后需重设小地图位置。目前不支持旋转小地图、地下分层自动识别和跨区域自动切换。

## 从源码运行

建议 Python 3.12 x64：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe run.py
```

运行测试：`.\.venv\Scripts\python.exe -m unittest discover -s tests -v`；打包：`.\build.ps1`。

## 说明

地图素材由使用者主动截图提供，处理均在本机完成。
程序通过系统截屏定位，不读取游戏内存、不注入、不自动操作角色。
