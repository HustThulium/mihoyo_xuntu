# 循图

原神地图叠加原型。用自己截取的局部地图建立区域，在底图上分色绘制路线、放置图片标记，并在游戏小地图上显示。

适用于 Windows 10 2004 及以上／Windows 11（64 位），游戏需使用窗口化或无边框窗口、小地图固定朝北。目前仍是原型，尚未完成真实游戏连续跑图验收。

## 使用

已有打包文件时，打开 `RouteOverlay.exe`；源码目录中可双击 `启动原型.cmd`。分发时请保留完整程序文件夹。

1. 选择游戏窗口，关闭游戏大地图，点击主面板的“小地图位置设置…”框选小地图。
2. 打开游戏大地图，调整到地形清楚的局部区域，点击“从游戏大地图建立区域”。
3. 框选地图并命名后，程序会直接回到主面板。区域名称旁的 `*` 表示有待保存的修改。
4. 在主面板选“画笔”并拖动画线，也可以放置图片标记。点击“保存区域”写入 `.routepack`，下次用“打开区域”继续编辑。
5. 关闭游戏大地图，点击“开始叠加”。也可先点击“加载离线演示（合成地图）”体验。

“画笔颜色”用于下一笔。点击“导入 PNG 标记”后，在底图上点击放置，可反复放置同一图标，按 Esc 结束。在“标记”模式点击已有图标即可选中，拖动可移动，也可调整大小或删除。标记的中心跟随地图位置，图标在缩放时保持固定的显示尺寸。Ctrl+Z 可撤销当前编辑会话里的笔画和标记操作。

已有区域时，点击“导入路线图…”并选择攻略图片。可匹配整图，也可框选路线及附近地形。确认页并排显示路线图选区和完整底图，绿色点标出对应地标，金色轮廓标出提取范围。若只匹配到拼图的一角，可以确认提取该局部，也可返回重新框选。找不到可靠位置时，可重新选区。

确认位置后，在预览下方用“显示范围”选择“全图”或“匹配区域”，用“显示内容”选择“叠加底图”或“只看本次墨迹”。调节提取灵敏度后进入清理步骤，可自动清理碎点或用橡皮擦修改本次墨迹。Ctrl+Z 撤销清理或擦除，返回调节会保留擦除范围。点击“保存墨迹”合入当前区块，再点“保存区域”写入文件。在主界面按一次 Ctrl+Z 可撤销整次导入。

`.routepack` v2 保存定位底图、透明墨迹、独立 PNG 素材和标记位置。v1 区域需要从游戏大地图重新建立。

按 **Ctrl+Alt+F9** 开始叠加，叠加期间再按一次即可停止并回到主面板。

主界面顶部的“小地图墨迹不透明度”默认是 **70%**。向右拖动，游戏小地图和匹配预览中的墨迹会更清晰。0% 时完全透明，100% 时完全不透明。松开滑块后自动记住设置。

开始叠加后，按 **Ctrl+Alt+F11** 或点击主面板的“截图模式”。定位成功时路线会冻结，此时可用 QQ 截图或 Windows 截图工具截取叠加画面。再次切换即可恢复定位。切到其他窗口时路线会暂时隐藏，回到游戏后截图模式仍然开启。移动角色前请退出截图模式。

点击侧栏左下角的齿轮打开设置。“通用 → 实时预览”中的“实时同步小地图”默认开启，更改后自动保存。关闭预览也可以继续叠加路线。

“通用 → 窗口行为”中的“开始叠加后自动最小化”默认开启，启动叠加时最小化程序并切回游戏。关闭后，点击“开始叠加”会保留当前窗口，手动切回游戏即可显示叠加层。停止叠加后，主面板会恢复到原先的最大化状态或普通窗口大小。

游戏必须处于前台且画面可见；窗口尺寸或游戏 UI 布局变化后需重设小地图位置。目前不支持旋转小地图、地下分层自动识别和跨区域自动切换。

## 从源码运行

建议 Python 3.12 x64：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe run.py
```

运行测试：`.\.venv\Scripts\python.exe -m unittest discover -s tests -v`；打包：`.\build.ps1`。

## 说明

地图素材由使用者主动截图提供，处理均在本机完成。
程序通过系统截屏定位，不读取游戏内存、不注入、不自动操作角色。
