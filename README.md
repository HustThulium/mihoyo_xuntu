# 循图

循图是原神路线叠加工具。用自己截取的局部地图建立区域，在底图上分色绘制路线，并在游戏小地图上显示路线和已有标记。

适用于 Windows 10 2004 及以上／Windows 11（64 位），游戏需使用窗口化或无边框窗口、小地图固定朝北。真实游戏连续跑图与失效恢复仍待完整验证。

## 使用

已有打包文件时，打开 `RouteOverlay.exe`。在源码目录中也可双击 `启动循图.cmd`。分发时请保留完整程序文件夹。

1. 选择游戏窗口，关闭游戏大地图，点击主面板的“小地图位置设置…”框选小地图。
2. 打开游戏大地图，调整到地形清楚的局部区域，点击“新建区域”。
3. 框选地图并命名后，程序会直接回到主面板。区域名称旁会显示保存状态。
4. 在主面板选“画笔”并拖动画线。点击左栏“导入路线图…”下方的“保存区域”写入 `.routepack`，下次用“打开区域”继续编辑。
5. 关闭游戏大地图，点击“开始叠加”。

绘制工具栏可直接切换“画笔”“直线”“橡皮擦”和“浏览”。画笔与直线共用颜色和线宽，线宽可设为 1–24 px，默认 3 px。画直线时按下定起点，拖动时预览，松手落笔。切换到“浏览”可拖动画布，滚轮可缩放。

橡皮擦可擦除手绘、直线和已导入的路线墨迹。直径可设为 1–512 px，默认 32 px。线宽和直径都可直接输入或用箭头微调，单位为底图像素。Ctrl+Z 可撤销一次绘制或擦除。

“显示内容”可选“叠加底图”或“只看墨迹”。“只看墨迹”用棋盘格呈现透明区域，两种模式都支持编辑，切换时保留当前缩放和位置。旧区域中的独立 PNG 标记继续随区域保存，并显示在“叠加底图”和游戏小地图中。橡皮擦只作用于墨迹层。

已有区域时，点击“导入路线图…”并选择攻略图片。可匹配整图，也可框选路线及附近地形。确认页并排显示路线图选区和完整底图，绿色点标出对应地标，金色轮廓标出提取范围。若只匹配到拼图的一角，可以确认提取该局部，也可返回重新框选。找不到可靠位置时，可重新选区。

确认位置后，在预览下方用“显示范围”选择“全图”或“匹配区域”，用“显示内容”选择“叠加底图”或“只看本次墨迹”。调节提取灵敏度后进入清理步骤，可自动清理碎点或用橡皮擦修改本次墨迹。Ctrl+Z 撤销清理或擦除，返回调节会保留擦除范围。点击“保存墨迹”合入当前区块，再点“保存区域”写入文件。在主界面按一次 Ctrl+Z 可撤销整次导入。

`.routepack` v2 保存定位底图、透明墨迹、独立 PNG 素材和标记位置。v1 区域需要从游戏大地图重新建立。

按 **Ctrl+Alt+F9** 开始叠加，叠加期间再按一次即可停止并回到主面板。

主界面左侧“游戏内叠加”中的“墨迹不透明度”默认是 **70%**。向右拖动，游戏小地图和匹配预览中的墨迹会更清晰。0% 时墨迹完全透明，100% 时墨迹完全不透明。松开滑块后自动记住设置。

游戏内小地图叠加层顶部会显示半透明的“循图墨迹层”水印，始终绘制在路线和标记上方。

开始叠加后，按 **Ctrl+Alt+F11** 或点击主面板的“截图模式”。定位成功时路线会冻结，此时可用 QQ 截图或 Windows 截图工具截取叠加画面。再次切换即可恢复定位。切到其他窗口时路线会暂时隐藏，回到游戏后截图模式仍然开启。移动角色前请退出截图模式。

点击底栏的“小地图预览”展开画面，再点“定位详情”查看匹配指标。首次成功框选小地图后会自动展开预览，方便核对范围。

点击侧栏左下角的“设置…”。在“外观”中可选择浅色（默认）或深色，立即应用并自动保存。“通用 → 实时预览”中的“实时同步小地图”默认开启，更改后自动保存。关闭实时同步也可以继续叠加路线。

请在可写目录中运行。设置保存在 `RouteOverlay.exe` 或 `run.py` 同目录的 `settings.json`。程序旁没有配置时，会复制 AppData 中已有的设置。清理旧配置前，请确认正在使用的程序目录中已生成 `settings.json`。分发程序时可省略个人配置。

“通用 → 窗口行为”中的“开始叠加后自动最小化”默认开启，启动叠加时最小化程序并切回游戏。关闭后，点击“开始叠加”会保留当前窗口，手动切回游戏即可显示叠加层。停止叠加后，主面板会恢复到原先的最大化状态或普通窗口大小。

游戏必须处于前台且画面可见；窗口尺寸或游戏 UI 布局变化后需重设小地图位置。目前不支持旋转小地图、地下分层自动识别和跨区域自动切换。

## 从源码运行

建议 Python 3.12 x64：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe run.py
```

运行测试：`.\.venv\Scripts\python.exe -m unittest discover -s tests -v`；打包：`.\build.ps1`。

## 说明

地图素材由使用者主动截图提供，处理均在本机完成。
程序通过系统截屏定位，不读取游戏内存、不注入、不自动操作角色。
