# 循图 · 原神小地图路线工具

## 功能简介

循图可以把自己画的路线和点位显示在原神的小地图上。你可以在地图底图上手绘，也可以导入别人画好的路线图，提取其中的路线。

循图通过系统持续截图，用图像识别确定小地图在底图上的位置，再在自己的透明窗口里画出墨迹，盖在游戏画面上方，像给小地图套了一层滤镜。整个过程只用截取到的画面，不读写游戏内存、不注入游戏进程，也不修改游戏原画面。

## 快速上手

适用于 Windows 10 2004 及以上和 Windows 11（64 位）。完整解压后，双击 `RouteOverlay.exe`。游戏请用窗口化或无边框窗口，小地图设为固定朝北。

1. **框选小地图。** 首次使用时，在循图里选择游戏窗口，关闭游戏大地图，再点「小地图位置设置…」。用一个正方形尽量贴合小地图的边缘。
2. **建立区域。** 打开游戏大地图，移到想画路线的地方，在循图里点「新建区域」，框选地图并命名。选区能覆盖路线和附近地形就够了，范围太大可能影响定位。建好后可用画笔手绘，或点「导入路线图…」提取墨迹，再点「保存区域」。
3. **打开已有区域。** 已经有 `.routepack` 文件，可以跳过建区和绘制，直接点「打开区域」。想先试效果，也可以打开随包提供的样例。
4. **开始叠加。** 关闭游戏大地图，点「开始叠加」，回到游戏并传送到对应区域。定位成功后，就能在小地图上看到路线和点位。按 **Ctrl+Alt+F9** 可以停止叠加。

## 试用随包样例

两份样例都在解压后的 `发布包样例资源` 文件夹里。

- **直接看叠加。** 完成小地图框选后，点「打开区域」，选择 `妖精绿艾-绿洲-样例.routepack`，再点「开始叠加」。回到游戏后，传送到 **特普洛绿洲** 的传送锚点。
- **试试导入路线。** 从游戏大地图截取特普洛绿洲附近的地形来新建区域，再点「导入路线图…」，选择 `妖精绿艾-路线图.png`。按提示核对匹配位置，保存墨迹后再点「保存区域」。

## 注意事项

- 循图主要为原神开发。其他游戏如果大小地图的地形外观一致、小地图方向固定，理论上也能用。
- 循图和 OBS 一样会持续获取游戏画面，在一些反作弊严格的游戏中可能触发检测机制。不建议在此类游戏中使用循图。
- 小地图上的「循图墨迹层」水印用于标明路线和点位来自循图，避免截图或录屏里的叠加内容被误当成游戏原生画面。
